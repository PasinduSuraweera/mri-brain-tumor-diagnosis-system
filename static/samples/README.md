# Sample scans

Images placed here appear as one-click "Try a sample scan" buttons on the home page.

Name each file `<class>_<anything>.<ext>`, where `<class>` is one of `glioma`, `meningioma`,
`notumor` or `pituitary` (e.g. `glioma_1.jpg`, `notumor_2.jpg`). Supported formats: JPEG, PNG, WebP, BMP.

Use images you are allowed to redistribute, e.g. a few files from the `Testing/` split of the
[Kaggle Brain Tumor MRI Dataset](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset)
(check its licence first).
